## Project Overview


This project was completed as part of the Digital Literacy course. It helped me by letting me to better understand the importance of understanding and properly utilizing the digital tools available to us.
Consists of five tasks: creating an infographic using canva, setting up digital portfolio, exploring online platforms, writing professional emails following proper etiquette, and understanding cybercrime along with preventive measures against it.
